When enabled, generated code uses VoiceoverScene, partition_segments, and <bookmark mark='s0' /> … so each segment animates at the matching point in your narration. Use Intro before first segment for speech with nothing on screen until s0. Optional Voice between this segment and the next adds extra narration after one Write finishes and before the next bookmark (b0, b1, …) with no new animation during that audio. Bookmarks need transcription_model="base" (Whisper). We pass transcription_kwargs={"language": "he"} so Whisper uses Hebrew. Set a spoken phrase per segment in the toolbox (recommended for math segments).
