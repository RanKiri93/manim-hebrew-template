# נכסים ל־README

## `readme_example.gif`

נוצר מ־`Example/example.py`, סצנה `TestScene`, באיכות נמוכה ל־GIF קטן לדף ה־README:

```bash
# מתוך שורש הפרויקט (נדרש תיקיית Example/ מקומית)
manim render Example/example.py TestScene -ql --format gif -o readme_example_gif
```

העתיקו את הקובץ מ־`media/videos/example/480p15/readme_example_gif.gif` ל־`docs/readme_example.gif` והעלו ל־Git.
